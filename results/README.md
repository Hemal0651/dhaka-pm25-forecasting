# Experimental Results and Generated Visualizations

This directory contains experimental artifacts, performance figures, evaluation metrics, and exported CSVs from the Dhaka PM2.5 forecasting and anomaly detection system.

---

## 1. Summary of Generated Figures

| Figure | Description | Key Insight |
| :--- | :--- | :--- |
| `fig_forecast.png` | Time series overlay of Actual vs Predicted PM2.5 for 2024 test window | LightGBM accurately captures diurnal spikes and seasonal winter surges. |
| `fig_scatter.png` | Scatter plot with 1:1 reference line ($R^2 = 0.557$, $\text{MAE} = 29.17\ \mu\text{g}/\text{m}^3$) | Strong linear alignment across moderate to unhealthy concentrations. |
| `fig_direct_horizon.png` | Multi-horizon forecast error (1h to 72h) vs persistence baseline | Direct LightGBM beats persistence across all horizons (up to 31.2% improvement at 12h). |
| `fig_error_vs_horizon.png` | Error progression comparison over extended horizons | Demonstrates error saturation dynamics in multi-step predictions. |
| `fig_confusion_aqi.png` | 6-tier EPA/DoE AQI categorical confusion matrix | Evaluates category-level classification across Good through Hazardous. |
| `fig_confusion_binary.png` | Confusion matrix for Severe Pollution alert ($PM_{2.5} > 150\ \mu\text{g}/\text{m}^3$) | 60.5% catch rate with low false alarm burden at default threshold. |
| `fig_pr_classifier.png` | Precision-Recall curve comparing Classifier vs Regressor vs Random | Classifier achieves PR-AUC = 0.645 (vs 0.157 random baseline). |
| `fig_quantile_band.png` | 80% prediction interval (10th to 90th percentiles) over ground truth | Empirical coverage of 79.2% (matching nominal 80% target), capturing peak risks. |
| `fig_importance.png` | LightGBM feature importance rankings (split and gain) | Long-term rolling means (`pm25_roll168`), temperature, and lag 1 lead predictive power. |
| `fig_longterm_forecast.png` | 2013–2024 monthly history + SARIMA 2025–2029 projection with 95% CI | Seasonal winter peaks remain persistent; long-term trend slope $+1.41\ \mu\text{g}/\text{m}^3/\text{year}$ ($p=0.189$). |

## 2. Exported Data Files

- **`anomalies.csv`** (14.4 MB):
  - 65,777+ evaluated rows with Isolation Forest outlier predictions (`anomaly = True`), decision function scores, and multi-sensor records.
- **`forecast_results_2024.csv`** (1.1 MB):
  - Hourly ground truth targets vs LightGBM predictions for all 3 monitoring stations across 2024.
- **`longterm_forecast_2025_2029.csv`** (1.8 KB):
  - Monthly seasonal forecasts through December 2029 generated by log-transformed SARIMA.
- **`results.zip`** (7.3 MB):
  - Complete archived bundle of all figures, tables, and serialized models for one-click downloading.
