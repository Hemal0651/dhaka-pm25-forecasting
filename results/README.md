# Experimental Results, Visualizations, and Benchmark Tables

This directory contains experimental artifacts, performance figures, evaluation metrics, CSV benchmark tables, and LaTeX tables generated by the Dhaka PM2.5 forecasting and anomaly detection research system.

---

## 1. Summary of Generated Figures

| Figure | Description | Key Insight |
| :--- | :--- | :--- |
| `fig_forecast.png` | Time series overlay of Actual vs Predicted PM2.5 for 2024 test window | LightGBM accurately captures diurnal spikes and seasonal winter surges. |
| `fig_scatter.png` | Scatter plot with 1:1 reference line ($R^2 = 0.557$, MAE = 29.17 µg/m³) | Strong linear alignment across moderate to unhealthy concentrations. |
| `fig_direct_horizon.png` | Multi-horizon forecast error (1h to 72h) vs persistence baseline | Direct LightGBM beats persistence across all horizons (up to 31.2% improvement at 12h). |
| `fig_horizon_strong_baselines.png` | Direct multi-horizon vs 3 strong baselines with 95% CIs | LightGBM significantly beats persistence, seasonal-naive, and climatology out to 72 hours. |
| `fig_error_vs_horizon.png` | Error progression comparison over extended horizons | Demonstrates error saturation dynamics in multi-step predictions. |
| `fig_confusion_aqi.png` | 6-tier EPA/DoE AQI categorical confusion matrix | Evaluates category-level classification across Good through Hazardous. |
| `fig_confusion_binary.png` | Confusion matrix for Severe Pollution alert ($PM_{2.5} > 150\ \mu\text{g}/\text{m}^3$) | 60.5% catch rate with low false alarm burden at default threshold. |
| `fig_pr_classifier.png` | Precision-Recall curve comparing Classifier vs Regressor vs Random | Classifier achieves PR-AUC = 0.645 (vs 0.157 random baseline). |
| `fig_calibration.png` | Probability calibration curve and reliability diagram | Extreme event classifier exhibits high calibration (ECE = 0.0071, Brier = 0.0797). |
| `fig_quantile_band.png` | 80% prediction interval (10th to 90th percentiles) over ground truth | Empirical coverage of 79.2% (matching nominal 80% target), capturing peak risks. |
| `fig_shap_summary.png` | SHAP beeswarm summary plot for top features | Quantifies directional impact of lags, rolling means, and weather variables. |
| `fig_shap_bar.png` | SHAP mean absolute attribution bar chart | Own PM2.5 history leads with 66.9% of attribution, followed by temporal/station features (17.0%). |
| `fig_importance.png` | LightGBM split-based feature importance rankings | Long-term rolling means (`pm25_roll168`), temperature, and lag 1 lead tree splits. |
| `fig_longterm_forecast.png` | 2013–2024 monthly history + SARIMA 2025–2029 projection with 95% CI | Seasonal winter peaks remain persistent; long-term trend slope $+1.41\ \mu\text{g}/\text{m}^3/\text{year}$ ($p=0.189$). |

## 2. Benchmark Tables (CSV and LaTeX for Publication)

| File Name (CSV / LaTeX) | Description |
| :--- | :--- |
| **`table_I_benchmark.csv`** / **`.tex`** | Full 24h benchmark comparing all 8 models (GRU, CatBoost, LightGBM v3+Optuna, LightGBM v3, LightGBM v1, Ridge, XGBoost, Climatology, Persistence) on identical rows with 95% bootstrap CIs. |
| **`table_II_strong_baselines.csv`** / **`.tex`** | Direct multi-horizon models (1h, 6h, 12h, 24h, 48h, 72h) vs Persistence, Seasonal-Naive, and Hourly Climatology with 95% CIs. |
| **`table_rolling_origin.csv`** / **`.tex`** | 6-year multi-period rolling-origin validation (2019 to 2024), demonstrating consistent $10.6 \pm 4.2\%$ improvement. |
| **`table_interval_coverage_station.csv`** / **`.tex`** | Raw vs Conformalized (CQR) 80% prediction interval coverage and width across CAMS-1, CAMS-2, and CAMS-3. |
| **`table_per_station_horizon.csv`** | Horizon-by-horizon error and improvement breakdown per individual monitoring station. |
| **`table_shap_families.csv`** | Feature contribution percentage grouped by functional family (History, Time/Station, Weather, Cross-station, Pollutants). |

## 3. Exported Data Files

- **`anomalies.csv`** (14.4 MB):
  - 65,777+ evaluated rows with Isolation Forest outlier predictions (`anomaly = True`), decision function scores, and multi-sensor records.
- **`forecast_results_2024.csv`** (1.1 MB):
  - Hourly ground truth targets vs LightGBM predictions for all 3 monitoring stations across 2024.
- **`longterm_forecast_2025_2029.csv`** (1.8 KB):
  - Monthly seasonal forecasts through December 2029 generated by log-transformed SARIMA.
- **`results.zip`** (7.3 MB):
  - Complete archived bundle of core figures, predictions, anomalies, and model checkpoints.
- **`results_extra.zip`** (0.5 MB):
  - Archived bundle of all extra publication figures, CSV benchmark tables, and LaTeX source tables.
